# RelayLab product outline: Home-Service Follow-Up Kit ($49)

**Status: outline.** This is not the finished product. Publishing gates (PRD §8): the content is original and source-checked, copyright and platform rules have been reviewed, and every item has a clear CTA.

**Buyer:** owner or office manager of a 2–30 person home-service business who wants a follow-up system before buying software.

**Promise:** a working follow-up routine in one afternoon, using tools they already have (email and a spreadsheet).

## Contents

1. **12 follow-up email templates.** Plain text, with merge fields in `{curly braces}`.
   - First response: acknowledge the request, then ask for the 2–3 missing details
   - Missing-details reminder (day 2)
   - Quote sent / quote explained
   - No-reply nudges (day 2, day 5) and a polite close-out (day 10)
   - Emergency-request response (safety line first)
   - Post-job thank-you and review request (the review request is optional; follow each review platform's rules)
   - Rules followed in every template: no prices in templates, no promised arrival times, no invented credentials
2. **Lead pipeline sheet.** Google Sheets and Excel. Columns: received, source, name, contact, job, status (new, contacted, quoted, booked, lost), next action, next action date.
3. **Quote checklists by trade.** HVAC, plumbing, roofing, electrical, cleaning, and remodeling: what to ask before quoting.
4. **Office SOPs (one page each)**
   - Who checks leads, how often, and the target response time
   - The missed-call playbook
   - A weekly 15-minute pipeline review
5. **Weekly dashboard template.** Leads, median first response, booked, lost, and win rate, with formulas included.

## CTA in every item

"Want this running automatically? RelayFlow drafts these follow-ups for every lead and waits for your approval." Link to the landing page.
